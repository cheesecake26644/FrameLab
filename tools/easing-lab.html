How to use this with Blender

Blender's Graph Editor controls how a value changes between keyframes. Linear interpolation moves at a constant speed; ease-in accelerates, ease-out decelerates, and ease-in-out does both. Try different presets above and watch the position indicator move along the track.

Use the CSV to inspect an example value at each frame, or reproduce the curve manually in Blender. This browser tool does not edit a .blend project or replace your character rig. For convincing movement, curves are only one part of timing, arcs, balance and posing.

Why overshoot can be useful

Overshoot briefly moves beyond the destination before returning. It can work for expressive secondary motion but should not be applied automatically to planted feet or rigid contacts.
