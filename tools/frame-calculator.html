What is frame timecode?

Video editors and 3D animators often specify moments as HH:MM:SS:FF: hours, minutes, seconds and a final frame number. At 24 fps, timecode 00:00:01:12 is one second plus twelve frames, so it represents 36 elapsed frames.

Why 23.976 and 29.97 need care

At fractional frame rates, the labels used for non-drop-frame timecode are based on the nearest nominal whole-number rate. For example, a 29.97 fps non-drop timeline counts labels as if there were 30 frames per second. That means the displayed timecode label is not exactly the wall-clock elapsed time. This calculator intentionally shows both values separately.

Important: this is a non-drop-frame converter. It does not implement SMPTE drop-frame timecode, which skips selected timecode labels to align with wall-clock timing. Confirm your editor's timecode convention before exchanging exact positions between projects.

Blender timeline note

Blender often displays timeline frame numbers starting at 1. If you want to know the time elapsed since frame 1, subtract 1 from the displayed frame number. For example, from the start of frame 1 to the start of frame 178, 177 frame intervals have elapsed.
