Field guide

Keep Blender video references in sync

Troubleshoot offset, timebase, viewport lag and broken frame correspondence without damaging animation.

A Blender reference can appear desynchronized for several different reasons. The source frame rate may differ from the scene, the reference strip may have moved, the scene's FPS settings may have changed, or viewport playback may simply be slower than real time. Fixing the wrong cause can damage otherwise valid work.

First: identify how your reference is loaded

A video in Blender might be a camera background image, a movie texture, an image-sequence reference or a strip in the Video Sequencer. Each has different timing controls. Find the original source file and determine which Blender component is responsible for displaying it.

Check exact frames before playing

Jump to a specific timeline frame and compare a recognizable event against the original clip at the computed source time. Then check a second point several seconds later. If both points are shifted by roughly the same amount, suspect a fixed offset. If the error grows, suspect a frame-rate or retiming mismatch. If frames match when scrubbing but not during playback, investigate viewport speed and playback sync settings.

Protect earlier work

When a project has a locked animation range, changing global scene FPS can affect evaluated timing everywhere. Instead of changing shared settings casually, preserve the protected scene and establish a clear mapping from the first editable frame onward. Save a recoverable version before technical repair.

Match the camera before posing

Apparent pose mismatches can come from camera height, field of view, subject scale or crop. Match a few stable landmarks and silhouette boundaries with side-by-side stills. Only after the camera and timeline are correct should you start refining arm, leg and facial poses.

Keep the reference separate from the output

Where possible, use non-rendering reference layers or dedicated collections and clearly named objects. Protect your reference from accidental transforms, avoid exporting it as part of the final scene, and label the start offset and source FPS in the project notes.

Minimum diagnostic checklist

  1. Find source file and exact FPS.
  2. Find the reference object or strip.
  3. Check scene FPS and FPS base.
  4. Check the first displayed source frame at a known scene frame.
  5. Compare two specific timestamps by scrubbing.
  6. Only then adjust offsets or rendering settings.
